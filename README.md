# J.A.R.V.I.S. Android-App

Nach dem Hochladen dieses Repos baut GitHub automatisch die App.
APK danach unter **Releases** (Tag `jarvis-app`) oder **Actions → jarvis-apk**.
Auf dem Handy herunterladen, antippen, installieren.
Beim ersten Start: Zahnrad (Einstellungen) -> Groq-API-Key eintragen (kostenlos: console.groq.com).
